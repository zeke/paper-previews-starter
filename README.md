[Paper](https://paper.design) is a great desktop app for doing agent driven graphic design.

This service makes those designs easy to review on your phone, with shareable
preview links hosted on Cloudflare.

Paste this into your agent to build your own version of this service.

```text
Let's build our own preview service for our Paper app designs.

https://github.com/zeke/paper-previews-starter
```

## Requirements

- macOS with Paper Desktop running and its local MCP server available.
- Node.js 24 or newer and npm.
- A Cloudflare account with permission to deploy Workers and static assets.
- Explicitly selected Paper files approved for public previews.

See [AGENTS.md](AGENTS.md) for setup, architecture, deployment and development.
